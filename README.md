# GenLayer Intelligent Contract: AI News Verification Primitive

## Overview
This repository contains a production-ready GenLayer Intelligent Contract designed for decentralized news fact-checking and off-chain content verification. 

By leveraging GenLayer's non-deterministic web-enabled consensus and LLM equivalence checks, this contract allows smart contracts to verify news authenticity without relying on centralized oracles.

## Key Features
- **Live Web Consensus:** Validators independently fetch real-time web news sources.
- **Equivalence Checking:** Generates a unified trust score (0-100) based on multi-validator consensus.
- **Reusable Primitive:** Can be integrated into prediction markets, Web3 social media platforms, and DeFi risk protocols.
